# Spesifikasi Platform

> Reviewer menolak draf yang melanggar batas ini (masuk R-06: akurasi terhadap spesifikasi).

## 1. TikTok — naskah video pendek

| Item | Batas |
|---|---|
| Durasi | ≤ 60 detik (≈ 130–150 kata naskah lisan) |
| Struktur wajib | HOOK (0–3 dtk) → isi (3–45 dtk) → CTA (45–60 dtk) |
| Teks overlay | Maks 6 baris, tiap baris ≤ 40 karakter |
| Emoji | Maks 2 |
| Caption | ≤ 150 karakter |

## 2. Instagram — caption

| Item | Batas |
|---|---|
| Panjang | ≤ 2200 karakter |
| Baris pertama | ≤ 125 karakter (sebelum "selengkapnya") |
| Hashtag | ≤ 30, dan **tidak boleh** memuat klaim (`#halal`, `#pemutih`) |
| Emoji | Maks 2 |

## 3. Marketplace — judul & deskripsi

| Item | Batas |
|---|---|
| Judul | ≤ 70 karakter, **tanpa emoji**, tanpa kata superlatif |
| Deskripsi | 3–5 poin, tiap poin ≤ 120 karakter |
| Wajib | **Nomor notifikasi BPOM** dicantumkan (R-02) |
| Wajib | Berat/isi bersih persis sesuai lembar produk |
